# WebUI 界面与验证

2026-10-22 按用户提供的截图改为白色三栏工作区，以细边框、浅灰背景和绿色状态标记组织内容。

## 布局与文件

- `public/index.html`：页面语义结构、导航、对话、输入框和执行面板。
- `public/app.css`：三栏布局、工具卡、消息、文件卡和响应式规则。
- `public/app.js`：现有 HTTP/SSE 接口的视图和交互，不承担 Agent 规划或工具执行。
- `src/server.ts`：显式提供 `/`、`/assets/app.css`、`/assets/app.js`，不开放整个工作区静态目录。

左侧显示本次页面打开后的真实会话。支持新建、切换、重命名；草稿、附件、消息、工具和事件连接分别归属对应会话。切换视图不会把正在运行的任务转移到其他会话。会话列表不提供数据库持久化，刷新页面后列表重置；后端同样没有重启恢复。

中间展示用户请求、Pi 模型回答、工具时间线、校验和产物。模型文本支持标题、列表、代码、粗体和链接，以 DOM 文本节点渲染，不执行模型返回的 HTML。输入框固定在底部，Enter 发送，Shift+Enter 换行。选择文件后自动上传；失败显示重试入口；路径显示实际 `/workspace/input/…` 或 `/workspace/output/…`，不是本地文件路径。

右侧的进度卡以 `toolCallId` 合并开始、更新和结束事件。UI 展示命令/输入及输出；RAW 展示完整调用参数和最新结果。前后按钮和滑块回看工具调用。日志保留每条原始 SSE 事件，文件页汇总上传文件和生成成果。进度摘要统计实际收到的工具调用，不伪装成模型事先制定的任务清单。

桌面显示全部三栏；中等宽度缩小导航；手机端通过抽屉打开会话与执行面板，可用遮罩、关闭按钮或 Escape 关闭。隐藏抽屉设置 `inert`，防止键盘焦点进入屏幕外的控件。图标来自随页面打包的 SVG，不依赖 CDN。

## 本轮验证

1. TypeScript 检查及前端 JavaScript 语法检查通过。
2. 82 项确定性测试通过，新增静态资源可访问、正确 Content-Type、工作区敏感文件不开放的检查。
3. `test:ui:layout` 在 Edge 中通过 12 组界面检查：欢迎页与延迟创建沙箱、建议提示、自动上传与路径、工具事件合并、UI/RAW/前后导航、日志/文件/实际浏览器下载、安全 Markdown、复制/重命名/收起导航、会话草稿隔离与停止、上传重试、1280/950/768/390 宽度、零 JavaScript 异常。
4. `test:ui` 通过真实 Pi/模型/E2B 的无附件计算、自动上传、10000 个整数排序、金标下载、实际浏览器保存、预览和来源标记。
5. `test:web:ui` 通过真实 Pi MCP/wigolo 的官方页面正文获取、来源卡片、准确链接和执行器标记。

交互回归使用 ReplayPi/MemorySandbox，不能证明模型生成或远程代码执行；真实服务验证单独列在第 4、5 项。截图与执行结果分别位于 `docs/evidence/current/ui-layout/`、`docs/evidence/current/webui.png` 和 `docs/evidence/current/web/`。

本轮首次联网 UI 验证因运行器 Node 24 与已安装 SQLite ABI 127 不匹配而失败，保留 `web/ui-failure.json`、`web/ui-failure.png`。使用本机匹配依赖的 Node 22.23.2 重新验证通过，结果见 `web/ui-smoke.json`。没有通过更换模拟来源或隐藏失败使检查通过。依赖准备与服务启动应使用同一 Node 主版本。
