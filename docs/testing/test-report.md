## 5. 大模型质量规则、样本和局限

六项基础规则均为0/1：文件金标/任务断言通过；存在非空回答；已发布文件名在该轮回答中可追溯；存在成功工具及通过校验事件；回答来源为pi-model且有agent_settled；中文请求至少出现中文字符。

局限：中文检测只查字符；非空和文件名不能证明所有事实正确；行数核对只是定向一致性规则，不能核验任意陈述。回答拼接保留全部assistant文本，包括规划和中间更新，尚未单独评价最终摘要完整度。此前R系列没有网页引用，记N/A；新增联网结果另述，不给旧评分追补满分。缺少真实无信息/恶意内容/错误格式样本和重复试验，不能从单轮9/10推断生产可靠性。统计成功不表示题目所有异常、安全与引用要求已经验收。

新增联网质量观察：W01实际调用search并获取fastify.dev正文，生成sources.md；搜索存在不相关页面与内容获取失败，模型随后据官网正文链接找到目标。初次来源文件只记访问日期，模型曾将受长度限制的正文称为完整内容，证据保留history/web-initial。仅补提示曾取得一次正确date -u时间，但再次运行仍把cached_at当访问时间，证据保留history/web-before-access-time。现由Pi原生tool_result钩子添加实际UTC的app_accessed_at，W01核对字段及产物时间属于本轮，前端另保留工具返回时间。没有通用自动事实评分，不能由这些定向断言宣称事实一致性全部通过。

联网W02复用同会话sources.md，在E2B执行Python统计，下载JSON为source_count=1。W03真实访问192.168.0.1的LAN策略拒绝，模型解释限制，没有成功来源卡片。独立MCP诊断获取官方页面11949字符并核对private IPv4错误。真实Edge提交Fetch后，链接、缓存标记、访问时间、执行器和零JS异常检查通过。原始记录和截图在current/web/，与此前R系列分开；未执行完整示例一或真实来源冲突专项。

复核发现早期私网测试的断言过弱：127.0.0.1实际返回ECONNREFUSED，而上游显式允许localhost/127/8；它证明连接失败反馈，不能证明策略拒绝。现改用192.168.0.1并校验private IPv4错误内容，修正前证据保留history/web-before-rejection-check。WIGOLO_FETCH_ALLOW_PRIVATE=false也不禁止上游的localhost例外，不能宣称MCP已具备完整宿主网络隔离。

应用只提交原始请求及附件元数据；Trace保留message_start/update/end、tool_execution_start/update/end、agent_settled。模型回复来自原生message_end，流式delta同时转发，不用脚本拼摘要冒充模型。工具事件带toolCallId和执行器。

宿主原生read/write/edit/bash被关闭，远程工具使用Pi原生工厂和E2B operations。内部桥需要随机会话token和active run；路径越权在扩展/网关阻止。工作区凭据不上传到E2B，状态接口不返回桥token。此处不能外推成真实模型攻击或敏感日志脱敏专项全部通过。可信stdio MCP运行在其所在环境，后续接入需单独验证权限。

## 8. 风险与后续优先级

1. 修复或降低D07类证据矛盾，扩大事实一致性/最终摘要/信息不足样本，并分模型重复执行；不承诺用一条提示词就解决幻觉。

4. 原生MCP搜索/Fetch及基本来源记录已通过；无结果/验证码/动态渲染、来源冲突、逐条引用正确性和完整示例一尚需专项。Chromium首轮下载慢未完成，已将大型浏览器安装设为可选；静态HTTP链路与Edge前端检查不受此影响。
5. 文件解析器/验证器的空输入、坏token和常见分隔符自动化通过，不代表Pi生成的每一个程序都支持任意格式；当前R01曾先按行解析再改成逗号，需更多真实格式回归。
6. 未完成真实提示注入/敏感信息攻击、公网身份认证/速率限制、新机器冷启动；默认本机演示范围明确。
